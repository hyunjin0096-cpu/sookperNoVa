```bash

python test.py --input <데이터 경로>/test/test.csv --image_root <데이터 경로>/test \

```

## 모델 설계와 근거
1. **순서형 분해 (Frank & Hall)**: 단계는 순서가 있는 값이므로 "k단계 초과인가?"를 묻는 이진 분류기
   5개를 따로 학습하고, 누적확률을 단조 보정한 뒤 단계 확률로 환원했습니다.
   일반 다중분류 확률과 가중 평균하며, 가중치는 OOF Macro F1 으로 고릅니다.
2. **실험 상대 정규화**: 배터리 형태·용량·유도 방식이 실험마다 달라 절대 온도 기준이 통하지 않습니다
   (EDA: 5단계 thermal_t 중앙값이 가열 40.6℃ vs 과충전 308.9℃).
   첫 관측 대비 변화, 현재까지 최댓값 대비 비율·하락폭, 최솟값~최댓값 구간 내 위치,
   최고값 갱신 후 경과 시간을 사용합니다. 모두 같은 실험의 과거·현재 관측만 씁니다.
3. **핫스팟 동역학 이미지 피처**: 밝기 통계에 더해 상위 90/97/99% 밝기 영역의 면적·무게중심·퍼짐·
   평균 밝기, 영상 기울기, 밝기 엔트로피, 의사색 색상 12구간 비율을 사용합니다.
   좌표는 이미지 크기로 나눠 해상도 차이의 영향을 줄였습니다.
4. **과적합 억제**: 피처 상위 <120>개만 사용, 시드 앙상블, colsample 0.4·reg_lambda 5.0.
5. **관측 간격 대응**: Test 에 10·15초 간격이 있어 학습 데이터를 2·3칸씩 솎은 복제본도 함께 학습합니다.

## 학습·검증 구성
- Train(78) + Validation(19) = 97개 실험을 합쳐 실험 단위 GroupKFold(5)로 평가했습니다.
  Validation 만으로는 5단계 비율이 Train 의 2배라 점수가 흔들려, 합쳐야 분포가 고르게 섞입니다.
- 블렌딩 가중치·피처 선택·전진 필터는 모두 이 OOF 로만 결정했고 Test 는 사용하지 않았습니다.
- 최종 모델은 97개 실험 전체로 학습했습니다.
- 점수: OOF 다중분류 <x> / 순서형 <x> / 블렌딩 <x> / 15초 간격 행 <x>

## 시계열 피처 구성
- 같은 experiment_id 안에서 relative_time_s 기준 과거 30·90·180초 구간 (t−w, t] 의
  평균·최댓값·최솟값·표준편차, w초 전 관측 대비 초당 변화율
- 현재까지 누적 최댓값·최솟값, 위 2번의 상대 정규화 피처
- 전압 3.0/1.0/0.1V 미만, t1 80/150/250℃ 이상이 처음 나타난 뒤 경과 시간 (임계값은 물리적 고정값)
- 미래 시점 관측, 실험 전체 기준 통계(전체 평균·최댓값·길이·순위), 다른 실험 관측은 사용하지 않음
- relative_time_s 원값은 입력으로 쓰지 않음
