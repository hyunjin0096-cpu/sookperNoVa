## 파일 구성
| 파일 | 역할 |
|---|---|
| `model.py` | 입력 컬럼 규격, 피처 생성(이미지 밝기·열 지수 통계, 센서·가스·실험 조건, 과거 방향 시계열), LightGBM 정의 |
| `train.py` | 간격 증강 포함 학습, Train GroupKFold로 설정 선택, Validation(원본·15초 간격)으로 확인, 모델·OOF 확률 저장 |
| `evaluate.py` | 저장된 모델을 Validation으로 평가(보정 전·후, 10·15초 간격, 유도 방식별) |
| `unet.py` | 임시 마스크 생성, U-Net 정의, 예측 마스크 → 모양 피처 |
| `train_unet.py` | U-Net을 Train 이미지·임시 마스크로 학습(라벨 미사용), `unet.pt` 저장 |
| `test.py` | 입력 CSV에 들어 있는 행만으로 추론하고 제출 파일 생성 |
| `model.joblib` | 학습된 가중치. 재학습 없이 `test.py`만으로 결과를 재현할 수 있어야 합니다. |

## 실행 방법
```bash
pip install -r requirements.txt

# 학습 (선택: --refit_train_val 을 주면 Train+Validation으로 최종 학습)
#   --augment_steps 2 3  : 10초·15초 간격 증강(기본값). 끄려면 --augment_steps 만 쓰기
#   --exclude <컬럼...>  : 피처에서 뺄 CSV 컬럼
python train.py --data_dir <battery_data_light 경로> --model_out model.joblib

# 추론
python test.py --input <battery_data_light 경로>/test/test.csv \
               --image_root <battery_data_light 경로>/test \
               --model model.joblib --output submission.csv \
               --sample_submission <battery_data_light 경로>/sample_submission.csv
```

## 시계열 피처 구성
- 같은 experiment_id 안에서 relative_time_s 기준 과거 30·60·120초 구간의 평균·최댓값, 윈도우 이전 관측과의 차이와 초당 기울기
- 직전 관측 대비 초당 기울기, 실험 시작부터 현재까지의 누적 최댓값(전압은 누적 최솟값), 첫 관측 대비 변화량
- 대상 신호: meas_v, meas_t1, meas_t2, meas_p, thermal_t, 이미지 img_p99·열 지수 통계, 가스 센서 0 개수
- Test의 넓은 관측 간격(10·15초)에 대비해, Train 실험을 2·3행 간격으로 솎은 복사본을 학습에 추가(교차검증 그룹은 원래 실험 ID)
- 미래 시점 관측과 실험 전체 기준 통계는 사용하지 않습니다.

## 센서 간 상호작용 피처 (v3)
- 파생 신호: 표면-양극부 온도차(t1-t2), 표면·양극부-주변 온도차, 열화상-표면 온도차, 가스 10종 log1p 합
- 파생 신호도 과거 윈도우 평균·최댓값·변화량·기울기를 계산
- 조합: 온도 기울기×전압 기울기, 온도 상승 & 전압 하락 동시 발생 플래그(고정 임계값 0.01℃/s, -0.0005V/s),
  가스 기울기×압력 기울기, 가스 상승 & 압력 상승 플래그, 온도 기울기×압력 기울기, t1·t2 기울기 차이,
  가속도(30초 기울기 - 120초 기울기)
- `--no_interactions`로 끄고 Train GroupKFold 점수를 비교해 효과를 검증

## 단조성 보정 (v3)
- Train 라벨에서 시간순 단계 하강이 0건이므로, 같은 실험 안에서 시간순 전진 필터(HMM forward filtering)를 적용
- 전이행렬은 Train 라벨의 5초 간격 전이 빈도(2단계 이상 점프 포함)로 추정하고, 관측 간격이 dt초이면 (dt/5)제곱으로 사용
- 반영 강도 alpha와 하강 허용 확률 down_eps는 Train GroupKFold OOF 확률로 선택(Validation 미사용). 개선이 없으면 자동으로 끔
- 현재 시점 이하의 모델 확률만 사용하므로 미래 행 제거·실험 분리·행 순서 변경에도 예측이 같음

## 물리 기반 지표 (v5, `ph_` 접두사)
- 열적(meas_t1, meas_t2): 30·60초 이동표준편차, 상승 가속도(최근 30초 기울기와 그 이전 30초 기울기의 차이), 기울기 부호 전환,
  과거 최고온도 대비 차이(peak gap), 최고온도 도달 후 경과 시간, 최고온도 갱신 여부,
  문헌 온도 구간(70/120/180℃: SEI 분해 / 분리막 손상 / 전극·전해질 분해) 누적 체류 시간과 최초 진입 후 경과 시간
- 전기·압력(meas_v, meas_p): 이동표준편차, 가속도, 과거 최고값 대비 하락폭(전압 강하율 포함), 최고값 이후 경과 시간
- 가스: 센서별 활성 여부, 활성 센서 수, 상관 그룹 log 합(HCN·HF·N2O·NO·NO2 / CH4·CO)과 그 시간 변화, 그룹 동시 활성
- 동시 발생: 온도 상승 & 전압 하락, 온도 상승 & 압력 상승 (과거 30초 기울기)
- 모두 같은 실험의 현재 시점 이하 관측만 사용. 온도 구간 값은 라벨 규칙이 아니라 입력 피처로만 사용
- 가스 0값은 '미발생'으로 단정하지 않고 활성 여부 피처로만 제공해 모델이 판단하게 함
- 압력은 단위가 불명확해 절대 임계값 없이 방향·변화량만 사용

## U-Net 모양 피처 (v4)
- 정답 마스크가 없어, 열 지수(고정 규칙)로 임시 마스크 2종(warm: 열 지수≥0.4, hot: ≥0.75)을 만들고 U-Net이 이를 따라 그리도록 학습
- 사전학습 가중치 없음, Train 이미지만 사용, 라벨 미사용. 입력은 128×128로 맞춰 원본 크기 정보 제거
- 예측 마스크에서 면적 비율, hot/warm 비율, 영역 안 열 지수, 고온 덩어리 수·최대 덩어리 비율, 퍼짐, 중심 이동, 경계 기울기, 규칙 마스크와의 차이를 추출
- 테스트 시 U-Net 피처는 CPU(스레드 4개 고정)로 계산해 재현성 확보

## 이미지 피처
- 흑백 밝기 통계 6개(베이스라인과 동일)
- 의사색 HSV 색상을 고정 규칙으로 0~1 열 지수로 변환(자홍·보라=0 → 빨강=0.9, 흰색=1)한 뒤 평균·표준편차·백분위·최댓값·고온 비율
- 이미지 크기·종횡비는 실험 식별 지름길이 될 수 있어 사용하지 않습니다.
